# Jobby App

A responsive job search web application built using React.js. Users can log in, search for jobs, filter jobs based on employment type and salary range, and view detailed information about job opportunities.

## Live Demo

https://jainuljobbyapp.ccbp.tech

## Features

- User login authentication using JWT tokens
- Protected routes for authenticated users
- Search for jobs using keywords
- Filter jobs by employment type
- Filter jobs by minimum salary package
- Apply multiple filters simultaneously
- View detailed information about a selected job
- View similar job opportunities
- Visit the company's website from the job details page
- Loading states while fetching API data
- Error and failure handling with retry functionality
- No jobs view when no results are available
- Responsive design for different screen sizes
- Not Found route for invalid URLs

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your system.

### Installation

Clone the repository:

git clone https://github.com/jainulfaisal/jobby-app.git

Navigate to the project directory:

cd jobby-app

Install the dependencies:

npm install

Start the development server:

npm start

The application will run locally in your browser.
